# TusmoLang

TusmoLang is a Somali programming language project focused on making software development more accessible through a familiar, native-language syntax.

The project is building a compiled language and its surrounding tooling with a long-term focus on **performance, memory safety, developer experience, and practical software development**.

### What we're building

* **Somali-first syntax** — programming concepts expressed naturally in Somali.
* **Compiled execution** — designed to produce efficient native software.
* **Memory safety** — a compiler-driven approach to managing memory without relying on a garbage collector.
* **Modern tooling** — including language-server features for a better development experience.
* **Native libraries** — expanding toward networking, graphics, games, and general application development.

### Status

🚧 **TusmoLang is actively under development.**

The language, compiler, standard library, tooling, and APIs are evolving as the project grows. It is currently a development project and should be considered experimental.

Our goal is bigger than creating another programming language.

We want to help build a future where **Somali can be a first-class language for technology and software development.**
